# Skill: Visual Novel Dialogue

## Purpose
Present branching dialogue using stable nodes, expressions, choices and conditions.

## Node Types
line, choice, branch, item_check, flag_check, quest_update, relationship_update, card_tease, end

## Rules
- Choices may change tone, clues, relationship, optional lore.
- Avoid accidental hard locks in main story.
- Dialogue history must remain readable after branching.
