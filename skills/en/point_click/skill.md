# Skill: Point-and-Click Interaction

## Purpose
Resolve hotspot and inventory interactions.

## Verbs
LOOK, TALK, TAKE, USE, COMBINE, GIVE, READ, SMELL, TASTE, REMEMBER

## Resolution
1. Read hotspot ID.
2. Check required flags.
3. Check selected item.
4. Resolve highest-priority valid action.
5. Return feedback if blocked.
6. Trigger dialogue, pickup, puzzle, or quest event.

## Rules
- No pixel hunting.
- Repeated clicks must not duplicate rewards.
- Wrong-item use returns characterful feedback.
