# Skill: Memory Card Collection

## Purpose
Reward discoveries and completed quests with collectible story cards.

## Categories
character, dessert, ingredient, place, craft, festival, belief, family_memory, community_story

## Unlock Flow
1. Receive card unlock request.
2. Check already-unlocked state.
3. Add new card ID.
4. Play reveal.
5. Add journal entry.
6. Recalculate card sets.
7. Apply set reward if complete.

## Rules
- No randomized paid acquisition.
- Cards come from discoveries or quest completion.
- Separate verified cultural notes from fictionalized story text.
