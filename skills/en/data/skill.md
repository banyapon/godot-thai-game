# Skill: Data Validation

## Purpose
Validate JSON-driven game content before runtime.

## Validate
unique IDs; cross references; quest→puzzle; quest→card; dialogue→flags; scene→exit destinations; item→targets; card→sets

## Severity
ERROR = breaks progression; WARNING = optional/localization issue; INFO = naming/style suggestion.

## ID Convention
Use lowercase snake_case, e.g. q_main_001, p_recipe_fold_001, card_memory_first_fold, scene_market_morning, npc_ya_noi.
