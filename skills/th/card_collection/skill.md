# Skill: Memory Card Collection

## เป้าหมาย
ใช้ Memory Card เป็นรางวัลจาก Discovery และ Quest Completion

## Category
character, dessert, ingredient, place, craft, festival, belief, family_memory, community_story

## Unlock Flow
1. รับ Card Unlock Request
2. ตรวจ Already Unlocked
3. เพิ่ม Card ID ถ้ายังไม่มี
4. เล่น Reveal
5. เพิ่ม Journal Entry
6. คำนวณ Card Set ใหม่
7. แจก Set Reward หากครบ

## กติกา
- ไม่มี Random Paid Acquisition
- การ์ดมาจาก Discovery หรือ Quest
- แยก Cultural Note ที่ตรวจสอบแล้วออกจาก Fictional Story
