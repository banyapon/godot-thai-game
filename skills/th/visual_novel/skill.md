# Skill: Visual Novel Dialogue

## เป้าหมาย
แสดงบทสนทนาแบบ Visual Novel ที่รองรับ Node, Expression, Choice และ Condition

## Node Type
line, choice, branch, item_check, flag_check, quest_update, relationship_update, card_tease, end

## กติกา
- Choice เปลี่ยน Tone, Clue, Relationship และ Lore ได้
- Main Story ไม่ควรถูกล็อกถาวรโดยไม่ตั้งใจ
- Dialogue History ต้องอ่านย้อนหลังได้หลัง Branch
