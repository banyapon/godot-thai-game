# Skill: Point-and-Click Interaction

## เป้าหมาย
จัดการ Hotspot และการใช้ Inventory กับวัตถุในฉาก

## Verbs
LOOK, TALK, TAKE, USE, COMBINE, GIVE, READ, SMELL, TASTE, REMEMBER

## ขั้นตอน
1. อ่าน Hotspot ID
2. ตรวจ Required Flag
3. ตรวจ Selected Item
4. เลือก Action ที่ Valid ตาม Priority
5. ถ้าทำไม่ได้ให้ Feedback
6. เรียก Dialogue, Pickup, Puzzle หรือ Quest Event

## กติกา
- ห้าม Pixel Hunting
- คลิกซ้ำต้องไม่แจก Reward ซ้ำ
- ใช้ Item ผิดควรมี Feedback จากตัวละคร
